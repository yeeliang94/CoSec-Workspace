## Provisional manual-to-software path

The following is a product proposal, not a sourced assertion about this firm's actual practice or a statutory checklist. Validate it with an executive and practising secretary.

| Step | Assumed manual activity | Proposed software support |
| --- | --- | --- |
| Establish opening file | Gather existing spreadsheets, records and previous returns; reconcile gaps. | Enter/import opening information with source, effective date, verification status and owned exceptions. Do not assume spreadsheet values are verified. |
| Identify upcoming work | Review a tracker or calendar and decide which clients to contact. | Create a company-year job from a reviewed obligation rule; show configurable internal preparation targets and overdue work. |
| Request confirmation | Contact the client outside the application and note missing responses. | Produce a confirmation checklist or draft pack; log dispatch, response, next chase date and owner. No automatic outbound messages. |
| Reconcile information | Compare replies against the file and identify changes. | Preserve the relevant snapshot, flag differences and create linked change jobs rather than silently overwriting history. |
| Prepare and review | Assemble particulars and supporting documents; secretary checks them. | Present checklist, evidence and exact version for review; make unresolved dependencies visible. |
| External filing | Use applicable external tools and portal. | Record actual prepared/submitted output, responsible staff, references, fees and evidence; preserve each attempt and query. |
| Follow up and close | Check outcome, retain records and update the tracker. | Keep outcome outstanding until evidenced; evaluate required work before closure and show next-period preparation separately. |
