# Supporting API action contracts

All settings changes POST `/api/settings`, base `{expectedRevision:number,requestId:UUID,action:...}`. Errors preserve draft input.

- `action: "defaults"`, `firmName`, `preparationLeadDays` (0–365), `chaseIntervalDays` (1–90), `defaultOwnerId` (user ID or null). New-work defaults only. Does not rewrite open work. Requires manage_catalogue.
- `action: "catalogue_draft"`, `kind: "template"|"checklist"|"rule"`, `name`, `content` (safe basic HTML), `source` (approved source/version or explicitly fictional basis), `effectiveDate:YYYY-MM-DD|null`, `predecessorId?:string|null`. Appends new draft with next version; cannot mutate published predecessor. Requires manage_catalogue.
- `action: "catalogue_publish"`, `versionId`, `confirmImpact:true`. Requires manage_catalogue AND review_pack, independent approver (creator cannot publish); valid source/date/non-empty content, known template placeholders, reviewable open-work impact. Publishes only for future selection, existing jobs retain pinned versions. This records internal review, not independent legal verification.

GET `/api/settings/preview?versionId=...` optional coordinator adapter calls `previewCatalogue(actor, versionId)` -> `{version,sampleHtml,affectedJobs:[{id,title,companyId}],effect}`. `effect` states future selections only, no automatic change to existing work. If no route, support getWorkspaceSupport adds no extra DTO; UI can preview locally escaped placeholders and show affected count from scoped jobs. Supported placeholders: `company.name`, `company.registrationNumber`, `company.address`, `job.title`, `job.year`, `job.anniversaryDate`, `job.effectiveDate`, `firm.name`, `today`. Values are escaped before insertion. Sample document always labelled illustrative.

POST `/api/preferences` `{textSize:"default"|"large"|"larger",density:"comfortable"|"compact",reducedMotion:boolean}`. Persists per actor. No template typography changes.

POST `/api/documents` multipart `companyId`, optional `jobId`, `title`, `file`. Accept PDF/PNG/JPEG/plain UTF-8 text <= 15 MiB. Returns immutable document metadata (no private path). Files remain private and are downloaded through scoped GET `/api/documents/:id`. `.docx` and other complex containers deliberately deferred pending policy/AV tooling.

Reminders reconcile inside every job change for that job's company, and at worker start, then every 60 seconds while the worker runs. Workspace loads only read them. Existing overdue dates remain visible after restart. Derived from job internal target, statutory date, unanswered outgoing next-chase, and unresolved filing query response. Complete/cancelled jobs do not suppress unresolved statutory/filing tasks unless those underlying tasks are evidenced resolved. Changing an internal/chase date resolves previous reminder occurrence while preserving ledger history. Reading notifications is unrelated to resolving work.

POST `/api/documents/generate` `{jobId,templateVersionId}` -> immutable document metadata plus `{sourceRevision,packVersion,templateVersionId}`. Requires prepare_job and company scope. Only a published, currently effective internal template may be used. Output is private UTF-8 text explicitly labelled illustrative, with exact job revision/pack/template version, a source hash and embedded source snapshot. W03 uses the captured anniversary company data; live changes cannot rewrite it. Attach the generated document through a new pack version as appropriate; generation never approves a pack or completes a job. Existing generated bytes are immutable.
